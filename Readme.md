# Network Cable Optimization using Minimum Spanning Tree

An interactive visualizer demonstrating Prim's and Kruskal's algorithms 
for optimal network cable layout in a college campus / office scenario.

## Features
- Interactive canvas — drag, add, delete nodes & cables
- Preset topologies: College Campus, Small Office, Hostel Block
- Real-time animated MST construction
- Step-by-step algorithm log
- Theory, C++ implementations, and comparison tabs

## Tech Stack
HTML5 Canvas · Vanilla JavaScript · CSS3
